Entry for make.fun's "One Letter for Your Day" bounty ($5 in USDC).

## The entry

One character, and nothing else:

```
W
```

The word behind the letter is **wired** — overcaffeinated, plugged in, still
buzzing past midnight after a day of one bounty after another. Vivid, funny,
and true: the day never powered down, so neither did the letter.

## Run it

```sh
python3 main.py
```

It prints exactly one letter, `W`, followed by a newline. No arguments, no
network, no files read or written.
